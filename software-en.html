biotimbre

A Python tool for building and managing libraries of animal sound templates, with similarity search based on audio embeddings (Perch v2 and BirdNET 2.4 are supported by default). Libraries can be used through a web interface or from the command line, searched by sound and by metadata, exported for analysis, and shared item by item with other libraries. Simple installation on Windows, macOS and Linux, with no prior Python installation required.

bioaccx

BIOAcoustic Custom Classifier eXchange: a Python command-line tool for training and sharing custom bioacoustic classifiers built on pre-trained foundation models such as BirdNET and Perch. Trained classifier heads are lightweight and can be shared separately from the backbone, or merged with it into a single ONNX or TFLite file. Training data can be assembled from local recordings, iNaturalist, Xeno-canto and Arbimon, all driven by a single configuration file.

Bioacoustic Python Notebooks

A collection of interactive notebooks for bioacoustics applications, ready to run on Google Colab with audio files stored on Google Drive or Arbimon. Includes audio analysis and BirdNET classification, computing and vector-searching embedding databases, classification from embeddings, model validation, classification results analysis and spectrogram calendars.

iNaturalist Sound Classifier

A browser extension for biologists and citizen scientists to analyze sound recordings directly on iNaturalist observation pages. It runs state-of-the-art machine learning models locally in your browser to identify species from sound, and validates detections against geographic occurrence data from GBIF and iNaturalist. Currently restricted to models in ONNX format. Available versions for installation: Chromium (Chrome, Brave, Edge) and Firefox.
