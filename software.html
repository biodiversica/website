biotimbre

  • Python
  • Web
  • CLI
  • embeddings

Ferramenta em Python para criar e gerenciar bibliotecas de templates de sons de animais, com busca por similaridade baseada em embeddings de áudio (Perch v2 e BirdNET 2.4 são suportados por padrão). As bibliotecas podem ser usadas por uma interface web ou pela linha de comando, pesquisadas por som e por metadados, exportadas para análise e compartilhadas item a item com outras bibliotecas. Instalação simples para Windows, macOS e Linux, sem necessidade de Python pré-instalado.

bioaccx

  • Python
  • CLI
  • ONNX
  • TFLite

BIOAcoustic Custom Classifier eXchange: ferramenta em Python de linha de comando para treinar e compartilhar classificadores bioacústicos customizados construídos sobre modelos fundacionais pré-treinados, como BirdNET e Perch. Os classificadores treinados são leves e podem ser compartilhados separadamente do modelo base, ou combinados com ele em um único arquivo ONNX ou TFLite. Os dados de treinamento podem vir de gravações locais, iNaturalist, Xeno-canto e Arbimon, tudo definido em um único arquivo de configuração.

Notebooks Python para Bioacústica

  • Jupyter
  • Google Colab
  • BirdNET

Coleção de notebooks interativos para aplicações em bioacústica, prontos para uso no Google Colab com arquivos de áudio armazenados no Google Drive ou no Arbimon. Inclui análise de áudio e classificação com BirdNET, cálculo e busca vetorial em bancos de embeddings, classificação a partir de embeddings, validação de modelos, análise de resultados de classificação e calendários de espectrogramas.

iNaturalist Sound Classifier

  • extensão de navegador
  • ONNX
  • GBIF

Uma extensão de navegador para biólogos e cientistas cidadãos analisarem gravações de áudio diretamente nas páginas de observação do iNaturalist. Executa modelos de aprendizado de máquina localmente no navegador para identificar espécies a partir do som e valida as detecções com dados de ocorrência geográfica do GBIF e iNaturalist. Atualmente restrito a modelos no formato ONNX.

Instalar: Chromium (Chrome, Brave, Edge) Firefox
